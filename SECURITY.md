# Security Policy

CheatMD for Obsidian runs the local `cheatmd` command-line tool for linting and inline execution.

Please report security issues privately by opening a GitHub security advisory for this repository:

https://github.com/cheatmd-dev/cheatmd-obsidian/security/advisories/new

Include:

- Plugin version
- Obsidian version
- Operating system
- Steps to reproduce
- Relevant logs or error messages, with private vault content removed
